Nicho inicial — Deporte funcional
Enfoque año 1
¿Por qué deporte funcional primero?
El deporte funcional (CrossFit, calistenia, HIIT, kettlebell) tiene la comunidad más activa en CDMX, la mayor densidad de boxes y studios en Condesa/Roma/Polanco, y los usuarios más comprometidos en términos de frecuencia (3–5 sesiones por semana). Es el nicho con mayor disposición a pagar, mayor facilidad para el matching por nivel, y donde el "no show" duele más — lo que hace que la propuesta de valor de SportMatch sea más clara y urgente.
🏋️
CrossFit / WOD
Matching por nivel RX, Scaled o Beginner. Eventos patrocinados por boxes.
🤸
Calistenia
Parques equipados de CDMX. Matching por habilidad: front lever, muscle-up, pistol squat.
⚡
HIIT / Bootcamp
Alta frecuencia semanal, ideal para comunidad recurrente. Intensidad como filtro.
🎯
Kettlebell / Fuerza
Nicho pequeño pero muy comprometido. Usuarios Pro por naturaleza.
Expansión futura: Una vez consolidado el nicho funcional con matching confiable en 2–3 zonas de CDMX, expandir a running, tenis, yoga y fútbol. El modelo de matching por nivel es el mismo — solo cambian los filtros.
Riesgo crítico
Seguridad y confianza entre desconocidos
Una mala experiencia viral = cierre del producto
No hay segunda oportunidad en early stage. El sistema de confianza es la condición de entrada al mercado, especialmente para el segmento femenino que representa el 60%+ del TAM en deporte funcional. Mitigación: 6 capas de verificación, comenzando desde el número de teléfono hasta verificación INE.
03
Sistema de verificación por capas
1
Obligatorio
Número de teléfono
OTP por SMS o WhatsApp. Bloquea bots y cuentas múltiples. Es el mínimo para crear perfil. Sin esto, la app no existe para ti.
✓ Requerido para usar la app
2
Obligatorio
Foto real de perfil
Foto frontal, no avatar. El algoritmo detecta si es selfie real vs imagen de internet. Revisión manual en casos dudosos. Se muestra siempre al compañero potencial.
✓ Requerido para publicar sesión
3
Verificación extra
INE / Identificación oficial
El usuario sube foto de su INE o pasaporte. OCR extrae nombre completo y CURP. Se valida contra el padrón del INE (API pública del INE). No se almacena la imagen — solo el resultado: "verificado ✓" con nombre inicial.
★ Diferenciador clave de seguridad
4
Progresivo
Rating post-sesión
Después de cada sesión, ambos participantes se califican. El rating se construye con el tiempo — usuarios nuevos tienen menos visibilidad hasta acumular reputación.
Opcional — aumenta visibilidad
5
Contextual
Modo "Solo Mujeres"
Las usuarias pueden activar que solo reciban y aparezcan en matches con otras mujeres. Verificación INE obligatoria para acceder a este modo.
Toggle en perfil — verificación INE requerida
6
Protección
Chat antes de revelar ubicación
La ubicación exacta del punto de encuentro solo se revela cuando ambas partes confirman via chat in-app. Hasta ese momento, solo se muestra zona general (ej. "Roma Norte").
✓ Por diseño — no modificable
04
Verificación INE — Cómo funciona
INE / CURP
Flujo de verificación de identidad oficial
Integración con el padrón electoral del INE — sin almacenar datos sensibles
01
Captura
El usuario fotografía frente y reverso de su INE o pasaporte desde la app. Guía visual que asegura buena calidad de imagen.
→
02
OCR + Extracción
OCR extrae nombre completo, CURP y clave de elector. Se puede usar AWS Textract o Google Vision con modelo entrenado para INE.
→
03
Validación INE
Se consulta el servicio de verificación del INE o CURP via RENAPO/CURP API del gobierno. Confirma que los datos son válidos y reales.
→
04
Badge + Borrado
Se asigna badge "Verificado INE ✓" al perfil. La imagen de la INE se borra inmediatamente. Solo se guarda el resultado: nombre, inicial y estado de verificación.
🔒
Privacidad por diseño
Nunca se almacena la imagen del INE en servidores propios. Se procesa en tránsito y se elimina. Solo el resultado booleano persiste.
⚡
Tiempo de verificación
30-90 segundos en condiciones normales. Si la API del INE falla, el usuario queda en estado "Pendiente de verificación" con acceso limitado.
📋
Marco legal
Requiere aviso de privacidad conforme a la LFPDPPP. El usuario consiente explícitamente el uso de sus datos para este único fin. Se puede usar proveedor como Metamap o Truora.
🛡️
Qué pasa si alguien falla
No puede usar el Modo Solo Mujeres. No puede publicar en zonas con alta demanda. Su perfil muestra "Sin verificación de identidad" — visible para otros.
05
Los 4 pilares de confianza
🆔
Identidad verificable
Teléfono + foto real + INE crea una tríada de identidad que hace extremadamente difícil operar de forma anónima con malas intenciones. El costo de crear una cuenta falsa es muy alto.
OTP SMS Foto selfie INE + CURP
⭐
Reputación acumulada
El sistema de ratings es el sistema inmune de la comunidad. Un usuario con 50 sesiones y rating 4.8 es auto-moderado por la comunidad. Los usuarios nuevos tienen menor visibilidad — incentiva el buen comportamiento desde el primer día.
Rating post-sesión Historial público Badges de antigüedad
💬
Revelación progresiva
La ubicación exacta es lo más sensible. El flujo de información es escalonado: zona general → chat → confirmación mutua → punto exacto. Nadie conoce tu dirección de salida si no hay confirmación de ambas partes.
Chat in-app primero Zona general → exacta Confirmación mutua
🚨
Reporte y consecuencias
Sistema de reporte en 2 taps disponible durante y después de la sesión. Tres reportes = revisión manual inmediata. Un reporte validado = suspensión. Las consecuencias son visibles — actúa como disuasivo efectivo.

Sistema de ratings post-sesión

Qué se califica — y por qué importa

Aparece 2 horas después de la sesión

★★★★★
Puntualidad
¿Llegó a tiempo? El "no show" sin aviso es la principal causa de abandono del producto. Se pondera x1.5 en el score.
★★★★★
Nivel declarado
¿El nivel (pace, intensidad) correspondió al perfil? Calibra automáticamente el matching futuro de esa persona.
★★★★★
Respeto y trato
¿Se sintió una experiencia segura y respetuosa? Este criterio activa revisión manual si es consistentemente bajo.
⚠️ Usuario con rating < 3.5 en "Respeto y trato" después de 5+ sesiones → suspensión automática pendiente de revisión. Sin excepciones.

♀
Un espacio exclusivo — no un gimmick
Las mujeres representan el 60%+ del TAM en yoga, pilates y running recreativo. Y son las que más barreras perciben al hacer deporte con desconocidos. El Modo Solo Mujeres no es una opción cosmética — es un requisito de producto para este segmento. Requiere verificación INE completa. Las sesiones en este modo muestran un escudo morado visible para todas las participantes. Solo disponible para usuarias con verificación de identidad completada.
